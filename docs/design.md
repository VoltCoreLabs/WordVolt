# Дизайн WordVolt

Статус: решения приняты 2026-10-17 (синий акцент, ribbon с вкладками, крупное скругление, комфортная плотность 32px).

## Принципы
1. **Блоки на фоне.** Окно = светлый фон (`bg`), на нём блоки (`surface`) с тонкой обводкой и скруглением. Ribbon, панели, диалоги — все блоки.
2. **Залитые кнопки с обводкой.** Кнопка всегда видна как кнопка: заливка + 1px обводка. Без «плоских» кнопок-призраков в основном UI.
3. **Практичность.** Минимум 28px высота кнопок (32px основной размер), чёткие состояния, подписи/подсказки (tooltip) с горячей клавишей.
4. **Токены везде.** Ни одного хардкод-цвета/размера в виджетах.

## Токены (светлая тема, стартовые значения)
Файл: `crates/wv-ui/src/theme/` — `colors.rs`, `spacing.rs`, `radius.rs`, `typography.rs`, `light.rs`, (позже `dark.rs`).

| Токен | Значение | Назначение |
|---|---|---|
| `bg` | `#F3F4F6` | фон окна (за блоками) |
| `surface` | `#FFFFFF` | блок/панель |
| `surface_alt` | `#F9FAFB` | вложенный блок, hover строк |
| `border` | `#D1D5DB` | обводка блоков и кнопок |
| `border_strong` | `#9CA3AF` | hover обводки |
| `text` | `#111827` | основной текст |
| `text_muted` | `#6B7280` | вторичный текст |
| `accent` | `#2563EB` | акцент (синий) |
| `accent_hover` | `#1D4ED8` | hover акцента |
| `accent_subtle` | `#DBEAFE` | активная/нажатая кнопка-переключатель |
| `danger` | `#DC2626` | деструктивные действия |
| `focus_ring` | `#60A5FA` | фокус клавиатуры |
| `page` | `#FFFFFF` | лист документа (всегда белый, и в тёмной теме) |

Отступы: 4 / 8 / 12 / 16 / 24. Радиусы: `sm 8` (мелкие элементы), `md 12` (кнопки), `lg 16` (блоки, панели). Обводка: 1px.
Тень блока: очень лёгкая (`0 1px 2px rgba(0,0,0,.06)`), без тяжёлых теней.

## Компоненты (`wv-ui/src/ui_kit/`)
Каждый — отдельный файл ≤ 300 строк.
- `block.rs` — контейнер: `surface` + `border` + `radius`; варианты `Block::panel()`, `Block::card()`, `Block::inset()`.
- `button.rs` — залитая кнопка с обводкой. Варианты: `Default` (surface+border), `Primary` (accent), `Danger`. Состояния: normal / hover / active / disabled / focus.
- `icon_button.rs` — квадратная кнопка с иконкой (ribbon).
- `toggle_button.rs` — B/I/U, выравнивание; включена = `accent_subtle` + `accent` обводка.
- `dropdown.rs`, `color_swatch.rs`, `separator.rs`, `tooltip.rs`, `block_group.rs` (группа кнопок в одном блоке с заголовком).

## Раскладка окна
```
┌ bg ─────────────────────────────────────────────┐
│ [Block: Titlebar / вкладки Home Insert Layout…] │
│ [Block: Ribbon — группы-блоки с кнопками]       │
│ ┌ Block: область документа ──────┐ ┌ Block ───┐ │
│ │      ┌─ page (белый лист) ─┐   │ │ Панель   │ │
│ │      └─────────────────────┘   │ │ (стили,  │ │
│ └────────────────────────────────┘ │ поиск)   │ │
│ [Block: Status bar]                └──────────┘ │
└─────────────────────────────────────────────────┘
```
Ribbon: каждая группа команд (Шрифт, Абзац, Стили…) — свой блок с подписью внизу.
