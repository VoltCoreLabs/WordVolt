# Решения (ADR)

## D-001 — 2026-10-17 — Язык и UI-стек
Чистый Rust (edition 2024), UI на **GPUI** через **gpui-kit** (+ gpui-component). Не egui.
Почему: GPU-рендер, свободный кастомный canvas для страниц, анимации (`with_animation`). Альтернативы (Slint, Floem, Iced) — только план Б.
Последствия: GPUI изолирован в `wv-ui`; версии закрепляем. Прототип анимаций в Этапе 0 подтверждает выбор.

## D-002 — 2026-10-17 — Платформы
Windows, Linux, macOS. Платформенный код только в `wv-ui`. CI-матрица на 3 ОС.

## D-003 — 2026-10-17 — Форматы

## D-004 — 2026-10-17 — Язык интерфейса

## D-009 — 2026-10-17 — Живая пересборка (dev-loop)
Полноценного HMR как в Tauri у GPUI нет. Цель: изменил код → окно обновилось за секунды.
Слои: (1) `bacon`/`cargo-watch` — пересборка и перезапуск при сохранении; (2) быстрая сборка в dev (lld/mold, `opt-level=1` для зависимостей, incremental); (3) **hot-reload токенов темы** из файла через `notify` без пересборки; (4) эксперимент: `subsecond` (hot-patching Rust) — оценить в Этапе 0; (5) сохранение/восстановление открытого документа при перезапуске.

## D-010 — 2026-10-17 — Иконки: Phosphor
Набор иконок — **Phosphor** (SVG, лицензия MIT), вместо Lucide из D-008. Файлы в `assets/icons/phosphor/` (стили regular/bold/fill), рисуем через GPUI `svg()`. Подключать только нужные иконки, не весь набор.

## D-011 — 2026-10-17 — Dev-команда
`cargo dev` (алиас в `.cargo/config.toml` → `cargo watch -x run` по `crates/` и `app/`). `just`/`bacon` не нужны, `cargo-watch` уже установлен. Уточняет D-009.

## D-012 — 2026-10-17 — Шрифт по умолчанию: SF Pro Text
Шрифт UI по умолчанию — **SF Pro Text**, запасные: Inter (OFL, лежит в репозитории) → Segoe UI. Файлы SF Pro лежат локально в `assets/fonts/SFProText-*.ttf` и **в git не попадают** (`.gitignore`): лицензия Apple запрещает распространять шрифт, а репозиторий публичный. Следствие: у других разработчиков и в релизных сборках SF Pro не будет, пока не решён вопрос с лицензией — там сработает Inter. Решение «ставить ли SF Pro в релиз» — открытый вопрос.

## D-013 — 2026-10-17 — Undo/redo через Edit-splice
Каждое изменение = `Edit { at, removed, inserted, before, after }`: подмена диапазона абзацев (клонируются только затронутые). Выбрано вместо обратных команд: проще и надёжнее, обратимость гарантирована для любой операции. Позиции пока индексами абзацев (не id) — перейти на id при появлении таблиц/объектов.

## D-014 — 2026-10-17 — Язык интерфейса по умолчанию: русский
Все строки UI — через `wv-i18n` (`Key` + обе локали); по умолчанию `Lang::Ru`. Хардкод строк в виджетах запрещён. Следующий шаг: переключатель языка в настройках.
