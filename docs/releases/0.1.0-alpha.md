# WordVolt 0.1.0 alpha

The first public build of **WordVolt**, a word processor written in pure Rust with
[GPUI](https://www.gpui.rs). This is an early **alpha**: it is usable for real documents, but
expect rough edges and missing features.

## What it can do

- **Text and paragraphs:** fonts, sizes, colours, highlights, alignment, lists, indents (with a
  ruler), tab stops (left / centre / right / decimal), line and paragraph spacing, block quotes,
  built-in and your own styles, a styles pane.
- **Pages:** A4/Letter and more, orientation, margins, columns, headers and footers, page numbers,
  sections with their own page setup, headers, footers and numbering.
- **Objects:** tables (merged cells, shading), pictures (move, resize, crop, rotate, text wrapping),
  footnotes, bookmarks, cross-references and page-number fields, table of contents.
- **Review:** comments with a side pane, tracked changes (accept / reject).
- **Files:** native `.wvd`, `.docx` (open and save), PDF export, Markdown and plain text, printing.
- **Also:** find and replace, spell checking (English, Russian), several documents in tabs,
  command palette (search box in the title bar, `Ctrl+Shift+P`), English and Russian interface.

## Known limitations

- The builds are **not code-signed**. Windows SmartScreen ("Windows protected your PC") and macOS
  Gatekeeper will warn you: on Windows choose *More info → Run anyway*; on macOS right-click the
  app and choose *Open*.
- The interface font (SF Pro) cannot be redistributed, so a system font is used instead.
- `.docx` support is partial: character and table styles, fields other than page numbers and
  cross-references, and some drawing objects are not read.
- Only Windows has been tested by the author; the macOS and Linux builds are untested.
- Not yet there: vertical ruler, tab leaders (dots), equations, text boxes, mail merge.

Feedback and bug reports are welcome in the issues.
